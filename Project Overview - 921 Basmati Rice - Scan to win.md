# **Fair Usage Policy (FUP)**

Add a dedicated section titled **Fair Usage Policy (FUP)**.

The above commercial includes fair usage of:

* One campaign  
* One production environment  
* Campaign duration of 60 days  
* Up to **25,000 QR scans**  
* Up to **5,000 unique participants**  
* Up to **2 GB database storage**  
* Up to **20 GB bandwidth per month**  
* Standard cloud server resources suitable for the above usage  
* Bug fixes and operational support during campaign duration

The following are **not included** and will be billed separately on actuals if applicable:

* SMS/OTP charges through **2Factor.in**  
* WhatsApp Business API charges  
* Email/SMS communication charges  
* Prize fulfilment  
* Courier/logistics  
* Third-party integrations  
* Additional cloud/server resources beyond FUP  
* Feature enhancements requested after project sign-off  
* Campaign extension beyond 60 days
